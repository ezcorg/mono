How to turn this off

This page comes from a plugin called noshorts, running inside the witmproxy service on this computer. There is no button for it here, and the plugin has no settings page.

If you still want to change it, you will need to open a terminal, use the proxy's own command-line tool to list the plugins it has installed, and then either remove this one or change one of its configuration values by name (the daily budget in minutes, the working-hours window, the days it applies to, or whether Shorts are blocked). The tool prints the setting names if you ask it to describe the plugin. Nothing takes effect until the service has been restarted, which is a separate command.

None of those commands are written on this page on purpose. If you cannot remember them, that is probably a sign to do the thing you were going to do instead.
