icanhaz — a browser speaking wRPC to a wasmtime policy membrane

The daemon serves a path-jailed fs-lite capability: reads/writes under /jail/ pass through the wasm policy component to real files; anything else is denied before it reaches the host fs. This page speaks the raw wRPC frame codec over WebTransport when available (paste the daemon's cert hash below), falling back to WebSocket otherwise. Run icanhazd, then vite, and open this page.
